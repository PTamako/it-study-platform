# SG 题库扩充与官方过去问接入方案

## 目标

把本项目从“少量自编题”扩展为可按年度、考试科目、领域和难度练习的 SG 学习平台，功能参考公开的过去问网站，但题目来源、版权和解说来源必须明确区分。

## 参考产品的功能模式

- [情報セキュリティマネジメント試験 過去問道場](https://www.sg-siken.com/sgkakomon.php)：年度/领域筛选、随机出题、模拟考试、选项顺序调整。
- [合格.dev SG](https://goukaku.dev/sg)：按年度组织科目 A/B，题目逐项解析。
- [IPA 官方公开问题入口](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html)：官方题册和答案例的首要来源。
- [e-Words SG 过去问索引](https://e-words.jp/p/e-sg-past.html)：年度范围及题库组织方式参考。

这些网站用于功能和目录设计参考，不直接复制其私有题库、解析文字、网页结构或抓取其受版权保护的内容。

## 题目来源规则

1. **官方公开题**：优先以 IPA 发布的题册和答案例为准。是否将完整题干、选项和图表存入数据库，必须遵循 IPA 当期明确的二次利用/引用条件，并记录出处、年度、科目、原始 URL、访问日期和许可说明。条件不明确的内容只存目录元数据，提供官方 PDF 链接，不镜像题文。
2. **授权题目**：只有在取得明确许可并保存许可记录后，才导入完整题目。
3. **自编题**：source_type 为 generated，由平台原创；不得标为官方真题。可按知识点补充大量题目和选项级解析。
4. **第三方网站**：可参考功能、知识点分类和公开目录，不批量复制题目、答案解释、插图或站点数据库。
5. **题目去重**：使用来源标识与稳定 ID；重新导入必须幂等，不能重复计数。

## 目标功能

- 年度/试次筛选、科目 A / 科目 B 筛选、主题标签、难度、关键词搜索。
- 顺序练习、随机练习、领域专项、错题重练、收藏、限时模拟考试。
- 每题显示来源标签和来源链接；官方题与自编题视觉上明确区分。
- 中文辅助：日语题干分句、关键词假名/中文解释、正确答案理由、每个错误选项的区别、常见干扰点。
- 学习统计：按领域正确率、反复错题、答题耗时、待复习列表。
- 科目 B 案例题按完整案例组织，保留共同背景、子问题、选项和答案关系，避免拆散上下文。

## 实施顺序

1. 建立来源目录和版权/许可元数据结构。
2. 盘点 IPA 公开题的年份、科目、题数及可用文件，并为每套题建立可点击的官方来源。
3. 根据确认可用的许可条件，逐批导入官方题；不满足条件的题只做官方链接入口。
4. 增加年度/领域筛选与题源标识，保持现有答题、统计和错题复习兼容。
5. 扩充自编题，按 SG 大纲覆盖管理、风险、技术、法务、服务管理和案例判断等主题。
6. 用类型检查、构建、迁移检查验证；远程 D1 仍需用户稍后统一执行迁移。

## 目前状态

本文件是实施规格，不代表官方完整题目已经导入。当前已有的 SG 扩充题为平台自编题。远程 D1 未执行迁移时，GitHub 中的 SQL 变更不会自动反映到线上数据库。
