# #149 — 语言语义复查：来源可追溯的纠错和剩余验收（2026-11-09）

## 本轮处理边界

依据生产发布工作流导出的 `language-quality-report` 与独立 `120` 行首批审校清单，检查日、英语原句、原社区中文译文、词条释义和当前高亮。审核类型为**AI 辅助语义初筛＋确定性回归测试**，**不是专家/母语者逐条人工认证**。所有校正都应通过公开源句、规则和测试复验；不凭空生成中文例句或缺失 IPA，不读取私人学习记录。

## 确定性误标，已修正规则并写入回归

| 真实误标或风险 | 修正 |
| --- | --- |
| `時のたつのは早いものだ` 的 `もの` 被切出“所属助词 の” | 保留完整名词、拒绝误拆 |
| `あとから電話します` 的“と”被当成助词；`ものが言えない` 被当成实体“东西” | 拒绝内部分词误释，补充完整用法 |
| `話す…よくない` 的 `よく` 被解释为“经常／很好” | 整体识别 `よくない`（不好） |
| `夢を見る` 的 `見る` 被当成一般视觉动作；`できるだけ` 被单解释为 `だけ` | 优先完整惯用搭配 |
| `I used to eat like a pig` 中 `like` 被释为“喜欢” | 介词比较义不套用动词释义 |
| `There is little chance of my meeting him again` 中 `meeting` 被释为“会议” | 识别 `my meeting him` 的动名词用法 |
| `said that` / 修饰从句中的 `that` 被释为“那个” | 不把连接词当成指示词 |
| `a lot of` 被截成 `a lot` 普通名词短语 | 标注完整数量短语 |
| `take a dump` / `make a phone call` / `leave a message` / `play it by ear` | 按完整习语解释，而不是按短词的字面义 |
| `I have an appointment` 的 `I have` 被说成“助动词” | 让完整句识别词汇义 `have`，不冒充语法助动词 |
| `Would you like…` / `would like to` 中 `like` 被说成“喜欢” | 优先礼貌征询意愿／邀请 |
| 日本语词库 `「ああ！」は感嘆詞だ`、`あと何時間`、`いくつもり`、`うんと暖かく`、`である` 被当成词义例证 | 否决引用元语言讨论、跨词边界、异义词与系词的假匹配 |
| ECDICT 形容词 `abandoned` / `advanced` 的过去时动词句被当作形容词示例 | 过滤有明确动词结构的错误义项例证 |

语句生成端、浏览器旧标注保护端与离线质量审计三方一起修复。匹配规则以**少一个高亮优于误导性解释**为原则。文档中的示例属于结构/义项边界的确认，不代表全语料的完备解析。

## 严格的数据边界与验收状态

- 首批 120 条包含原句、中文译文、Tatoeba 链接及具体高亮释义；对确定误标写入固定正反例，其余保持“待人工复核”。不能将机器标注为人工验证。
- 全量静态词库每语种 3,010 词，句库每语种 5,000 句；质量门禁要求 0 结构错误。每次 CI 产出 JSON 和 120 行 CSV 以持续发现问题。
- 2026-11-09 原始基线：日语尚缺可靠完整双语例句 1,111、英语 127；来源关联但**未人工核验义项**日语 1,889、英语 2,873。更新后的数字以 CI 报告为准，不承诺填满。
- 其他译句、英语一词多义与日语活用歧义，无法仅靠来源链接严格判定，因此 #149 的**全部人工语义认证部分不得关闭**，直到真实审核记录覆盖目标词条。
- 不追加无出处内容、不查询/清洗生产用户 D1、不更改个人完成记录或复习进度。
