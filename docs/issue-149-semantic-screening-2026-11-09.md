# #149 — 语言语义复查：来源可追溯的纠错和剩余验收（2026-11-09）

## 本轮处理边界

依据生产发布工作流导出的 `language-quality-report` 与独立 `120` 行首批审校清单，检查日、英语原句、原社区中文译文、词条释义和当前高亮。审核类型为**AI 辅助语义初筛＋确定性回归测试**，**不是专家/母语者逐条人工认证**。所有校正都应通过公开源句、规则和测试复验；不凭空生成中文例句或缺失 IPA，不读取私人学习记录。

## 确定性误标，已修正规则并写入回归

| 真实误标或风险 | 修正 |
| --- | --- |
| `時のたつのは早いものだ` 的 `もの` 被切出“所属助词 の” | 保留完整名词、拒绝误拆 |
| `あとから電話します` 的“と”被当成助词；`ものが言えない` 被当成实体“东西” | 拒绝内部分词误释，补充完整用法 |
| `話す…よくない` 的 `よく` 被解释为“经常／很好” | 整体识别 `よくない`（不好） |
| `夢を見る` 的 `見る` 被当成一般视觉动作；`できるだけ` 被单解释为 `だけ` | 优先完整惯用搭配 |
| `I used to eat like a pig` 中 `like` 被释为“喜欢” | 介词比较义不套用动词释义 |
| `There is little chance of my meeting him again` 中 `meeting` 被释为“会议” | 识别 `my meeting him` 的动名词用法 |
| `said that` / 修饰从句中的 `that` 被释为“那个” | 不把连接词当成指示词 |
| `a lot of` 被截成 `a lot` 普通名词短语 | 标注完整数量短语 |
| `take a dump` / `make a phone call` / `leave a message` / `play it by ear` | 按完整习语解释，而不是按短词的字面义 |
| `I have an appointment` 的 `I have` 被说成“助动词” | 让完整句识别词汇义 `have`，不冒充语法助动词 |
| `Would you like…` / `would like to` 中 `like` 被说成“喜欢” | 优先礼貌征询意愿／邀请 |
| 日本语词库 `「ああ！」は感嘆詞だ`、`あと何時間`、`いくつもり`、`うんと暖かく`、`である` 被当成词义例证 | 否决引用元语言讨论、跨词边界、异义词与系词的假匹配 |
| ECDICT 形容词 `abandoned` / `advanced` 的过去时动词句被当作形容词示例 | 过滤有明确动词结构的错误义项例证 |

语句生成端、浏览器旧标注保护端与离线质量审计三方一起修复。匹配规则以**少一个高亮优于误导性解释**为原则。文档中的示例属于结构/义项边界的确认，不代表全语料的完备解析。

## 二轮生成后新增的边界验收

首轮改动生成的最新语言质量报告仍为 **0 结构错误**。对比更新后的首 120 句，新的候选显示出另外几类易混淆搭配，因此继续补充：

- `Would you like to leave him a message?`：`leave him a message` 是给他留言；新增通用代词宾语变体并防止错误展示单个 `leave`。
- `There is a post office close by.`：`a post office` 是邮局；`close by` 表示在附近，不是关闭。
- `I am very sorry that ...`：`that` 引导内容从句，不是指示词“那个”。

生成器与浏览器端兼容旧高亮，CI 新增固定正反例。**替换的是不准确的学习高亮，不是原始语句、用户学习记录或 Tatoeba 社区译文。**

### 同形词的第二候选也要复核

仅排除第一条有误例句还不够；下一条自动评分胜出的句子仍可能是错义项。生成后的候选报告再次发现：

- “比尔擅长辩论”、“邁克歌唱得很好”、“贝尔发明了电话”，原词语分别是人名，不是 `ビル／マイク／ベル` 的建筑、麦克风和铃的义项。
- `Some bugs were fixed.` 的 `fixed` 是修复动作的被动式，不是词条 `fixed` 对应的“固定的”。

除对具体例句的上下文过滤外，关联时进一步参考**原社区中文译文中明确写出的专有名词**（比尔／邁克／贝尔／特朗普，保留繁简体），以及英文被动语态中的软件修复宾语。正反例同时验证不会误杀 `ビルは高い／マイクで話す／ベルが鳴った` 与 `a fixed price`。

这些修正仍不能等同所有人名变体或所有词性义项已审完；其他无证据的歧义继续保持来源关联**待人工核验**。


## 第四轮：首批 120 句中的日语助词误义项（2026-11-09）

复核 [Cloudflare production Actions #42566766731](https://github.com/PTamako/it-study-platform/actions/runs/42566766731) 发布的完整 `language-semantic-first-120.csv`。发现下列**可以通过句内结构明确证伪**的语法高亮，已在生成器、浏览器旧数据兼容逻辑、离线质量审计同步保护，并新增独立正反例测试：

- `チェックできない` 中的 `で` 是动词「できる」的组成部分，不是动作场所／手段；
- `もう一歩で` 和 `あと二日で` 中的 `で` 为条件／经过时间等语境，不宜泛解为地点／工具；
- `生きる上で` 中的 `で` 属于「动词＋上で」的整体表达；与 `机の上で` 的真实地点用法必须区分；
- `フランスへと出発` 中的 `へと` 是方向强调，不可把 `と` 解为“和／引用”；
- `天気予報では` 指预报所述的信息，不适合套用“动作场所／手段”；
- `かかってくるの。番号…` 的 `の` 为前句末尾语气词，即使后面还有另一句，也不能解释为名词所属。

保留正例 `学校で勉強する`、`机の上で本を読む`、`本とノート`，不能通过全局禁用助词粗暴修复。疑似社区译文问题继续沿用原社区译句与来源警告，不擅自覆盖。
