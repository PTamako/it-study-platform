## 练习、错题与掌握度

- [ ] 普通练习答题后即时显示判分与解析，并成功写入 `study_attempts`。
- [ ] 错题集只包含实际答错过的题；按考试和来源过滤正确。
- [ ] 再复习列表只显示未掌握且已到复习时间的题；暂无到期题时显示空状态，而非假数据。
- [ ] 连续答对三次可自动标记掌握；手动标记掌握/未掌握均能成功写入 D1。
- [ ] 重新答错后掌握状态重置、复习间隔缩短；刷新页面后复习状态仍然存在。
- [ ] “掌握、再复习、错题集”分别有正确数量/空状态，并可从复习流程继续作答。
- [ ] 网络失败时提示结果未同步；不能只显示本地判分却让用户误以为已保存。

## 模拟考试与成绩统计

- [ ] 模拟考试必须加载 60 道不重复题目；题量不足时明确阻止开始，不得用重复题补足。
- [ ] 限时 120 分钟，时间到自动交卷，未答题按错题计。
- [ ] 交卷后正确率、得分、未答题数、答题明细一致；每题答题记录成功写入 D1。
- [ ] 普通练习完成一组、模拟考试交卷、手动添加成绩均写入 `exam_history`，刷新后记录仍在。
- [ ] `GET /api/dashboard` 的累计答题数与正确率只依据真实 `study_attempts` 记录计算；考试历史汇总不重复计入答题数。
- [ ] 历史成绩曲线按本地日期正确显示；没有数据的日期保持为空，不伪造 0%。
- [ ] 旧 localStorage 成绩导入 D1 后，重复刷新不会重复创建同一成绩记录，也不会因云端为空而覆盖尚未同步的本地数据。
