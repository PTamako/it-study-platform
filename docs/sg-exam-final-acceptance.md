# SG 考试备考模块最终验收清单

本清单用于合并 PR 与部署前的验收。目标数量不等于实际数量；只有远程 D1 查询结果才能作为线上题量依据。

## 题库数量与真实性

- [ ] 历年真题目标：448 道。逐题核验 source_type='official'、年度/场次/题号、官方题目来源与官方答案；图表题若无法忠实呈现则不导入，不用原创题补数。
- [ ] 预测题库目标：660 道。全部标记为 source_type='generated'，不得伪装成 IPA 官方题。
- [ ] 检查 ID 唯一性、重复题（题干/选项近似重复）、空题干、选项数量、答案 ID 是否存在于选项中。
- [ ] 每题均有解释；解释与正确答案一致，日语题干/选项可正常显示，中文解释不乱码。
- [ ] 年度、场次、题号、题源链接与主题分类准确；主题统计来自实际题目数据，而不是写死的计数。
- [ ] 页面题量、分类数量、API 返回量与 D1 实际查询一致。迁移未执行时必须明确显示未完成，不得展示目标数冒充现有数。

## 练习与复习闭环

- [ ] 单题练习：选项可选、提交后即时判分，正确答案和解析对应当前题目。
- [ ] 每次作答成功写入 study_attempts；刷新页面后历史记录仍可读取。
- [ ] 错题集只显示答错题，错误次数/最近作答状态准确；重新答对后状态更新符合设计。
- [ ] 「再练习」可重新进入练习，不会跳到空白页或重复提交旧答案。
- [ ] 「未掌握」可加入/移出，筛选结果与用户状态一致。
- [ ] 到期复习与普通错题、未掌握列表的入口互不覆盖；无数据时有明确空状态。
- [ ] 分类筛选会传入 API 并过滤真实题目；切换考试后题库、来源、分类均同步切换。
- [ ] 分页/加载更多不会重复题目或漏题；题目列表、随机练习与模拟考试之间的状态不串线。

## 模拟考试

- [ ] 固定抽取 60 道不重复题，满分 120 分，每题 2 分，限时 120 分钟。
- [ ] 倒计时在刷新/离开页面时的行为符合产品定义；超时与主动交卷都能完成判分。
- [ ] 未作答题目交卷后按错误记录，并能进入错题复习。
- [ ] 交卷后显示得分、正确率、答题数、未答数、各主题表现与复习建议。
- [ ] 题量不足 60 道时禁止静默重复凑数，并明确提示题库尚未满足模拟考试要求。

## 可用性与兼容性

- [ ] iPhone Safari 小屏幕下无横向溢出、按钮可点击、选项文字完整。
- [ ] 加载中、网络失败、空题库、提交失败均有清晰提示和可重试路径。
- [ ] 切换考试、切换题源、切换分类、返回页面后状态正确，不显示上一次搜索/筛选的残留结果。
- [ ] 题目来源可辨识；官方过去问与原创预测题在列表、作答和复盘页均有明确区别。

## 数据库、迁移与发布

- [ ] 所有迁移编号连续且按顺序执行；迁移可重复执行（使用稳定 ID 与 INSERT OR IGNORE 等幂等方式）。
- [ ] 远程 D1 应用迁移后核对真实计数、重复 ID、空字段、答案合法性和来源字段。
- [ ] npm run typecheck、npm run build 与 CI 全部通过。
- [ ] 验证 /api/health、/api/tracks、/api/questions、/api/wrong-questions 和作答写入 API。
- [ ] PR 保持未合并，直到题量、答案核验、移动端与 CI 验收完成；合并后再确认部署工作流和线上健康检查。
- [ ] 不把本地/PR 迁移中的题量描述为线上已生效题量。

## 当前已知待办

- [ ] 历年真题仍需持续补齐至 448 道；本次新增的 2019 年秋期第 25、26、27、30 题只是一个小批次，不能视为目标达成。
- [ ] 预测题库需在迁移后查询 D1，确认实际数量达到 660 道。
- [ ] 最终验收必须基于真实远程 D1 和 CI 结果；代码里存在迁移文件不代表数据已部署。
