# 本地词典与 D1 免费额度优化（2026-11-03）

## 为什么优化

过去普通词典查询的服务端调用 `GET /api/dictionary` 不仅查找 `vocabulary` 中的 IT 术语，还为公开访问计数写入 `public_dictionary_rate_limits`，随后查询 `language_cards` 并视情况访问外部翻译。因此即使是平台已有的常用词，每次查询仍会消耗 D1 资源。日英语句子卡片此前已经使用静态资源；这次把相同策略应用于公开词典。

## 实施结构

| 操作 | 请求位置 | 常规 D1 使用 |
| --- | --- | --- |
| 查已收录的日语/英语词条 | `/learner-lexicon/{ja,en}.{hash}.json`，浏览器会话内索引 + 缓存 | **0** |
| 显示许可日语例句与来源 | 同一静态词库文件 | **0** |
| 查看语言学习原有 5,000+5,000 句子 | 已有 `/language-cards` 静态资源 + 本地原创扩展 | **0** |
| 普通词典的生词/未命中词句 | 现有在线 API、授权翻译与反滥用限流 | 可能有 D1 读取和写入 |
| IT 专用术语 | `vocabulary`，先索引精确匹配，后别名/多语言回退 | 需要 D1 |
| 收藏、复习、答题、个人进度 | 既有认证 API | 需要 D1 |
| 查看 AI 剩余次数 | 仅用户主动点击 | 需要 D1 |
| AI 补充或本地词条缺少的第三语言翻译 | 仅用户主动点击 | 可能需要 D1 |

`GET /api/dictionary` 接受 `static_word_checked=1`：只有前端成功查过本地静态文件（或用户选择为已命中本地词条补译）时才传递，从而让 Worker 不再对同一学习词库重复查询 D1。直接调用 API 的旧版客户端仍使用 D1 词典回退。此参数只省略公开字典的重复查找，不会绕过鉴权、请求限流或个人数据保护。

词条来自固定版本的 ECDICT（MIT）、OpenJLPT/Tomoshi/JMdict 衍生内容（CC BY-SA 4.0）、有独立出处的 Tatoeba 例句（CC BY 2.0 FR），以及自编校订的高阶学习条目。静态文件**只包含公开学习内容**，绝不包含账户收藏、登录资料、复习记录或私密数据；自编词条明确标注为原创而非官方考试词表。英文 ECDICT 转写不冒充 IPA。

## 构建方式和验证

- 执行 `python scripts/build_static_learner_dictionary.py`：只读取仓库已提交的 `migrations/0079_language_learning_6000_cards.sql` 和 `scripts/curated-learner-words.json`；通过本机 sqlite3 校验并输出每种语言的指纹 JSON 文件及 manifest。此生成器**不访问生产 D1，也不会下载网络数据**。
- 当前编译结果预计为每种语言 3,000 条许可证词条 + 10 条原创校订词条，共 6,020 条静态词条；各自按需加载，页面不会一次下载两个词库。
- `scripts/static-learner-dictionary.test.mjs` 验证生成文件指纹、来源、重复词、中文例句和零 Worker 读路径。
- GitHub PR CI / Production CI / 本机检查脚本都在测试之前构建词典，确保前端发布的资源存在。
- 生产 D1 迁移 `0115` 创建复用索引，`0116` 添加 44 条原创句子用于正常同步复习，`0117` 删除已确认重复的语言分类索引，`0118` 创建 IT 术语无大小写精确索引。迁移只在合并后的发布流程执行，不在 PR 阶段读写用户生产数据。

## 内容质量

- 44 条原创进阶长句（22 日语 + 22 英语）：工作进度、延期、条件、让步、礼貌请求、回滚、排查问题等。每条有中文释义、两段有效词汇/语法高亮。新句只追加，不替换现有 10,000 条许可句子。
- 20 条自编日英实用词组：逐项记录中文含义、使用限制、自然场景例句、中文例句翻译及另一种目标语言对应表达。不会自动生成未校验的 IPA、声调、词性或来源。
- 对普通日英词条尝试按已有英文释义/词性分组；已有释义不充分的条目可主动使用在线翻译或 AI 语境解析，不把翻译回填为权威内容。

## 仍会发生的 D1 操作

原有 IT 模式、匿名在线回退的速率限制、云端收藏和学习进度等仍会消耗 D1；静态词典仅保证**命中静态词条时不进行 D1 查词**，不代表整个网站的每日 D1 使用总量为零。上线后需要检查 Cloudflare D1 Analytics 的读取/写入曲线，以及移动端和 iPad 对大词典 JSON 的缓存和内存表现。
