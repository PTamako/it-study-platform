# 中日英互译与 IT 术语模块 — 验收说明

## 功能范围

- 自动识别英文（拉丁字母）、日语（假名和常用日本汉字）及常见中文（简体字、常用中文短语）。
- 支持手动指定中文、日语、英语。**纯汉字存在重叠**：例如「認証」同时使用汉字，自动识别默认保留日语专业词；需要中文含义时切换「中文」以消除歧义。
- 中文输入显示日文和英文翻译；日文输入显示中文及英文对应词/释义；英文输入显示中文译文、日文译文及在线英语词典的详细英语定义（可用时）。
- 中、日、英三种语音按钮：语音播放由浏览器的 SpeechSynthesis 提供，分别使用 zh-CN、ja-JP、en-US，并支持暂停/继续/停止。设备没有对应语言语音时明确告知，不回退到其他语言。
- 英语词典仍保留 IPA 音标（提供方有数据时）与精选片假名辅助读音（不是英文音标）。
- IT 模式只查询 D1 的 `vocabulary` 和别名，不向第三方翻译服务发送请求；支持用中文释义检索术语。普通模式如果本地 IT 命中，也优先使用 D1 的中文、日文和英文释义。
- 使用现有生词本保存完整三语结果快照；**不重置**学习进度、既有收藏、练习成绩或数据库表。
- 翻译优先使用已有精选离线译文及现有线上翻译源；无法翻译时不伪造成功译文。服务端免费翻译源可能被限流，部分词句不可用。

## 自动化验收

- `node --test scripts/dictionary-trilingual.test.mjs`：测试中文自动检测、原有英日查询、双向三语结果、纯汉字手动覆盖、D1 IT 离线优先和中文朗读界面。
- `npm test`：保证旧词典、iOS Safari 发音、云端收藏及其他平台功能未退化。
- `npm run build`：Vue/TypeScript 编译无误。
- `wrangler d1 migrations apply --local`：全套已有迁移可执行；本功能无需新表或数据清理迁移。
- `wrangler deploy --dry-run`：Worker 可正常打包。
- 合并后 GitHub Actions 生产部署需完成健康接口、未登录保护及语料检查。

## 真实设备手动检查

1. 自动识别查询「你好」「认证」「情報」「こんにちは」「hello」「authentication」，观察识别语言是否符合预期；「情報」与其他模糊汉字词应可手动切换中文/日语。
2. 分别在中文、日语、英语模式输入短词句，确认其他两种语言的译文；无提供方译文时显示可理解的失败/空状态。
3. 逐个点击「中」「日」「EN」按钮，检查首次点击、停止/暂停/恢复、语音语言是否符合提示（iPhone Safari 与桌面浏览器）。
4. 选择 IT 离线模式查询「認証」「认证」「authentication」；断网时这些收录词仍可通过 D1 API 查询，但设备本身访问 D1 仍需网络（**不是完全离线 PWA**）。
5. 将中文词条收藏到生词本并刷新、重新登录、其他设备同步，确认新中文释义与原有收藏均保留。

这份说明描述本轮新功能；不表示所有免费翻译服务具有可用性保证，也不表示真实设备发音已经由 CI 验证。

## 传统词典优先、AI 按需补充（2026-10-31）

- 普通中日英查词只使用离线精选词、Free Dictionary、Jisho、原有翻译服务；**不会自动触发 Workers AI**。IT 离线模式保持使用本地 D1 术语库。
- 在词条卡片或传统查词失败时，用户可点击「AI 补充翻译与用法／AI 解释语境与多义词」。AI 返回中文解释、三语对应词和短例句，结果明确标为「AI 辅助解析」，不冒充权威词典。
- 模型为 Cloudflare Workers AI 的 `@cf/meta/llama-3.1-8b-instruct-fp8`，设置有限输出 token、低温度，并视原文和既有词典释义为不可信文本。
- AI API `POST /api/dictionary/ai` 必须已登录、同源、通过速率限制；公开 GET `/api/dictionary` 不调用 Workers AI。
- D1 `dictionary_ai_daily_usage` 按日本日期原子计数，最多 **20 次新推理尝试/日（整个平台）**；多标签页同时提交也不能超过。AI 服务失败也可能产生费用，因此计数不退回。已缓存、输入条件相同的解释可在 30 天内复用，不扣新次数。
- `GET /api/dictionary/ai/status` 显示剩余调用次数；接口与个人状态均受认证保护。模型不可用或用量已满时，**原词典及生词本仍可正常使用**。
- AI 响应属于参考资料，可能不准确。不会覆盖用户保存的词条、原有专业术语、学习进度或答题记录。
- 自动测试覆盖常规查词零 AI 调用、缓存命中免费、并发超额阻断、未配置模型、模型失败、恶意输入长度、前端状态与保护性认证检查。真实设备点击和实际模型效果仍需手动体验。
