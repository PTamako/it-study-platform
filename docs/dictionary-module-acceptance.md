# 英日发音词典与 IT 术语模块验收清单

## 1. 产品范围

本模块的主要目标是辅助英语学习，而不是中日英三语互译：

- 英语查询：显示英语词条/缩写、英语释义、在线词典提供的 IPA 音标（如有）、已收录时的日语片假名近似读音、日语辅助理解和例句。
- 日语查询：显示日语词条、日语读音，以及可获得的英文对应词/释义。
- 发音：分别提供“EN 英语原音”和“日语读音”按钮。片假名只是近似提示，不能取代 IPA 或母语音频。
- IT 模式：只查询 D1 本地术语表和别名；命中本地条目时不请求第三方翻译。词库不可用时应明确提示数据库迁移问题，未知词不得伪造释义。
- 中文词典模式/中文翻译：当前不在 UI 中提供，API 的 `lang=zh` 也会返回 400。

## 3. 自动化 CI 检查

GitHub Actions 验收应至少包含以下三步，并且全部成功：

- [ ] TypeScript 类型检查与前端构建
- [ ] 从干净本地 D1 开始依次应用所有迁移，包括 `0076_expand_offline_it_dictionary.sql`
- [ ] Worker bundle / dry-run 成功，且没有发布生产版本

CI 只证明代码能构建、迁移能运行和 Worker 可打包；它不会验证真实设备是否有声音。

## 4. 手动功能验收

建议在桌面 Chrome/Safari 与 iPhone Safari 各完成一次：

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 英语普通词 | 查询 `hello`，选择英语 | 显示英语释义；词典有 IPA 时显示 IPA；已收录时显示“ハロー”等近似读音 |
| 英语 IT 词 | 查询 `authentication` 或 `source code` | 命中本地库时显示来源标记、英语对应词/定义和日语辅助读音，不依赖翻译接口 |
| 日语 IT 词 | 自动识别查询 `認証` | 按日语词条查询，显示日语读音与可获得的英文对应词 |
| 发音按钮 | 分别点击 EN 和日语按钮 | EN 读英语原词；日语按钮读日语/片假名；状态显示开始、完成或失败，两个按钮不串语言 |
| 语音不可用 | 在禁用/缺少对应系统语音的环境测试 | 页面有明确失败提示，不能静默无反馈，也不能把英语交给日语声音播放 |
| IT 离线 | 选择“IT 术语（离线）”，查询 `CORS`、`トランザクション` 和随机未收录词 | 已收录词显示本地内容；未知词显示无结果；网络断开时仍可查已收录词 |
| 中文接口 | 请求 `/api/dictionary?q=hello&lang=zh` | 返回 HTTP 400；正常页面不出现中文翻译请求或中文语言按钮 |
| 生词本 | 收藏、刷新、取消收藏，再从另一台设备打开同一 Worker | 收藏状态及英日释义可同步；删除后云端和本地均不再显示 |
| 外部词典异常 | 临时阻断外部词典/翻译请求后查普通词 | 页面给出无结果或明确错误，不假装翻译成功；IT 本地查询继续可用 |

## 5. 尚需真实环境确认的项目

1. **音频设备验收：待执行。** CI 无法验证 macOS/iOS 系统语音是否实际发声。必须听到英语与日语两个不同声音，并检查首次打开页面及快速连续点击。
2. **英语近似读音覆盖率：持续补全。** IPA 以外的片假名近似读音目前只为精选常用词和本地 IT 术语提供；未收录的普通英语单词不应自动生成不可靠的片假名。
3. **在线词典可靠性：外部依赖。** 免费第三方词典可能超时、限流或没有某个词；该情况不能靠本地 IT 词库完全解决。
4. **部署后 D1 状态：待线上确认。** 合并后需确认远程迁移 `0076` 已成功应用，且 `/api/dictionary?q=CORS&lang=it` 能读到本地条目。
5. **跨设备生词本：需手动端到端确认。** 代码包含 D1 同步，但需要用实际部署环境核对保存、刷新、另一设备读取及取消收藏全流程。
