# 全平台验收与 UI 优化清单

> 用途：合并与生产部署前的验收门槛。源码级测试、CI、预览环境与真实 iPhone 操作分别记录；任何一层未通过，都不能标记为“全平台已验收”。

## 发布阻断项（P0）

- [ ] **语音播放：iPhone Safari**（日语/英语播放、连续播放、暂停/继续、切换模块停止旧语音已由用户在 iPhone Safari 实测通过；异常边界与设备详情仍待补齐）
  - 首次打开页面后，日语和英语各播放一次；必须实际听到声音。
  - 连续点击播放、切换句子、切换模块、暂停/继续/停止后再播放。
  - 当浏览器报告 `onend` 但用户听不到声音时，界面不得把它描述为“已确认播放成功”；应显示“播放请求已结束”并提供下一步排查信息。
  - 目标语言语音列表为空、没有匹配语言、播放超时、`onerror` 时都必须有可理解的状态提示。
  - 确认同一时间只有当前请求更新状态；旧请求的结束/错误事件不能覆盖新请求状态。
  - 记录 iPhone 型号、iOS 版本、Safari / 主屏幕 Web App、扬声器或耳机、页面显示的语音名称及实际结果。
- [ ] **生产安全与数据边界**
  - 所有个人学习数据 API 必须要求服务器端会话认证；未登录请求应返回 401。
  - 本项目采用不依赖 Zero Trust、不要求付款信息的单人登录方案；配置步骤见 [免费单人登录配置](./free-single-user-auth.md)。
  - 检查所有写入型 API 是否有字段校验、持久化速率限制及来源/CSRF 策略；当前单人登录不等同于适用于公开多人使用的账户体系。
  - 确认没有把 Token、API Key、个人数据或环境文件打进前端包/提交到仓库。
  - 清除/删除数据操作必须二次确认，失败时保留原数据并清楚说明。
- [ ] **部署安全**
  - Validate 全绿；D1 migration dry-run/本地空库顺序迁移通过；Worker bundle 通过。
  - 预览环境通过后才允许合并；合并后单独验证部署工作流、`/api/health`、关键 API 与 D1 数据。
  - 未验证主 Worker 前不删除历史 Worker 或数据库。

## 模块功能验收（P1）

### 首页、学习计划与统计
- [ ] 空数据、加载中、API 失败、部分同步失败均有明确状态；不显示伪造的统计值。
- [ ] 今日任务跨刷新保留；本地与云端数据来源有清楚区分。
- [ ] 窄屏无横向溢出，主要操作无需精确点按小目标。

### 考试题库与错题复习
- [ ] 历年真题与预测题库分开筛选、分开标注来源；官方链接目录不冒充站内真题。
- [ ] 作答、提交、判分、解析、错题集、再练习、未掌握、已掌握及复习计划形成完整闭环。
- [ ] 空题库、网络失败、重复提交、切换考试/题目时状态一致。
- [ ] 手机端选项完整可读；长日语题干、代码/术语、解析不会被裁切或溢出。

### 语言学习卡片
- [ ] 仅保留“日常会话”和“职场语言”两类主要分类。
- [ ] 日语与英语卡片结构一致：原句、词汇高亮、语法高亮、整句含义/示意、逐词解释、逐项语法解释、例句/扩展与发音入口。
- [ ] 词汇与语法高亮颜色可区分且有文字图例，不只依赖颜色表达。
- [ ] 每个高亮项都能在解释区找到对应条目；算法未能识别时显示不确定提示，不把通用提示冒充准确语法分析。
- [ ] 列表、卡片详情、主动回忆、下一句/上一句、掌握状态与发音控制在手机端可操作。

### 词典与 IT 术语

> 2026-10-25：用户报告 iPhone Safari 以下项目通过：普通在线查词、超时与失败提示、英语原音与日语辅助读音、生词本收藏与取消、IT 离线术语。限流场景与跨设备同步尚未单独确认；因此本模块整体端到端验收仍未全部勾选。
- [ ] 普通日语/英语查询的加载、无结果、限流、超时和重试状态清楚。
- [ ] IT 离线模式只查本地术语；未知词不伪造定义，离线已收录词可查。
- [ ] 英语原音和日语辅助读音按钮不会串语言；缺少可靠读音时明确提示。
- [ ] 收藏、取消收藏、刷新与跨设备同步通过端到端验证。

### 实战训练
- [ ] 情境、选项、判分、反馈与历史记录端到端可用。
- [ ] 切换情境或离开模块会停止旧语音，旧请求不覆盖当前状态。

## UI / 无障碍验收（P1）

- [ ] iPhone Safari 常见窄屏宽度下，无页面级横向滚动、遮挡、固定栏压住内容或按钮超出视口。
- [ ] 主要点击目标建议至少约 44 × 44 CSS px；图标按钮有可访问名称和明确状态。
- [ ] 文字与背景对比度可读；交互状态不只靠颜色表达。
- [ ] 异步加载、错误、语音状态使用适当的状态播报区域，避免每次长文本更新都造成过度播报。
- [ ] 页面标题、按钮名称、焦点顺序、键盘操作和表单标签一致。
- [ ] 空状态、错误状态、长文本、超长术语、没有图片/语音、慢网络等边界均有布局。
- [ ] 动画与自动轮播可控；尊重减少动态效果偏好（如存在自动动画）。
- [ ] 统一按钮层级、间距、圆角、卡片标题和状态提示；避免同一动作在不同模块使用不一致文案。

## 验收结论规则

- **通过**：自动化与必要的真实设备/预览验收均通过。
- **有条件通过**：有明确非阻断项、责任与后续计划。
- **未通过**：任何 P0 项失败、生产数据风险未澄清，或语音在目标设备仍无声。
- 不得将“构建成功”“事件触发 `onend`”单独描述为“语音播放已验收”。
