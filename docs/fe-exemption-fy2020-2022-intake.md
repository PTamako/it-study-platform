# 2020～2022 FE 修了認定試験：出典付き収録と重複除去

## 「CBT正式過去問」は非公開、修了試験は公開

IPAは2020～2022年度の基本情報技術者（FE）CBT本試験の問題・解答を非公開としている。ただし **科目A（旧午前）免除制度の修了認定試験** の問題・答案は公開されている。

- [IPA 科目A免除制度・過去問題](https://www.ipa.go.jp/shiken/about/menjo-fe.html)
- [e-Words 2020年6月修了](https://e-words.jp/p/e-fe-past-R0206.html)（再出題の参考・独自解説はコピーしない）
- [e-Words 2021年6月修了](https://e-words.jp/p/e-fe-past-R0306.html)
- [e-Words 2022年6月修了](https://e-words.jp/p/e-fe-past-R0406.html)

**公式の問題・答案リンクは前の PR #111 / migration 0124 で 12 場すべて登録済み。** 12×80＝960 は出典上の出題枠数であって、独立な練習問題数ではない。2020年12月回だけでも多数が再出題と判明しており、重複は除去する必要がある。

### データの分離と D1無料枠

1. Migration `0125_fe_exemption_provenance.sql` は既存 `questions` に `exam_origin='general' | 'fe_exemption'` を **ALTER ADD COLUMN** で追加するだけ。従来の公式問題・改編・サンプル・SGは変更しない。
2. `fe_exemption_occurrences(sitting_date,original_question)` は日付・原問号ごとの出題記録を保持。1対多の `canonical_question_id` で同一問題の本文・復習履歴を1件だけ格納する。
3. Migration `0126_fe_ipa_exemption_first23.sql` は追加・再実行が安全な `INSERT OR IGNORE` のみ。登録対象は**23問題+24出題記録**。ユーザーの習熟度、問題回答記録を変更しない。
4. API `source=exemption` と FE の `2020 / 2021 / 2022` 年次フィルタで登録済みの修了試験練習題のみを取得できる。通常の `licensed`（真題改編）と `sample`（2022公式サンプル）から区別し、公式CBT本試験に混入させない。
5. 日常演習は従来のページネーションで1ページだけ読む。**未検証の960件を空のダミー問題として一括投入しない**。
6. 模擬試験は元々全行をD1から取得してシャッフルしているため、別Issueで DB側の限定サンプリングへ改善する。

## 今後 #112 で継続する範囲

各年度の残りの出題、2020年6・7・12月と翌1月、2021年6・7・12月と翌1月、2022年6・7・12月と翌1月の全12回を公式PDF・正解表ごとに段階採録し、既存の別年度の問題と題文が完全に一致するものは出典関係のみ追加する。図、表、疑似言語は必ず再現可能なテキスト/図版で保持する。現代の科目Bと旧午前の区別を維持する。
