# 知学平台 2.0（不含 FE 约 3,000 题扩充）验收矩阵

更新时间：2026-11-04。本文基于代码、CI 和生产 D1 **只读**检查；不将「存在源码」混同于「用户真实设备体验通过」。

## 功能交付与质量证据

| 模块 | 代码/自动化状态 | 仍需确认 |
| --- | --- | --- |
| SG 与现有 FE 题目练习 | 答题/错题/来源筛选/模考/实战/中断恢复及原子提交已有测试 | 不包含 FE 3,000 题长期扩充；抽样手工验证原题答案与题源 |
| 日语+英语每日学习 | 每种语言含日常、职场场景；每日词汇、语法重点、2+1 题及对话听力 | 内容不标称为官方 JLPT/ETS 真题；真实学习时长及效果不能由 CI 推断 |
| 语言卡与词典 | 10,000 条指纹静态句子、来源标注，许可词典本地命中免 D1；语法高亮与词典失败回退有回归测试 | 开放词典的词性/音调缺失时不猜测；复杂句分析仍不能等同形态素解析器 |
| 复习、收藏、个人进度 | 已有三级复习、云端进度、错题和生词收藏去重测试 | 两设备同时修改/断网恢复需分别实机核对 |
| 语法与听力的答题同步 | 本机 localStorage + IndexedDB，认证后按日期、语言小批量写 D1；听力按复合主键索引 | 生产个人会话操作需由持有者真实登录验收；不得写模拟用户数据到生产 |
| 跟读录音 | 设备麦克风权限、最长 30 秒、录音回听，不上传音频；源码和 CI 已验证 | iPad/iPhone Safari 的麦克风、暂停/结束和后台切换须真机检查 |
| 云端安全与低成本 | 个人 API 需认证；同源写入限制，公开词库和句子静态缓存；生产部署校验 401 与资源指纹 | 无法仅由源码判定所有免费额度消耗；以 Cloudflare Usage 真实曲线为准 |
| 大屏辅助练习 | 题目下方白板、计算器、手写与 Apple Pencil 入口已实现 | iPad 纵横屏、手写误触与页面滚动需要真机验收 |

## 发布门槛（自动化）

1. PR 运行 Node 22 类型检查、全部回归测试、前端构建、完整本地 D1 migration 和 Worker dry-run。
2. main 发布先应用版本化 D1 迁移，再用五条 **只读 LIMIT 0** 查询检查个人课程相关表与字段；缺失则阻断 Worker 部署。
3. 部署后检查静态语言资源指纹、`/api/health`、未登录个人 GET/POST 均为 401；不能以 API 401 代替真实登录下的同步测试。
4. 课程和词典静态资源缓存命中不产生 D1 查询；需要云端进度、收藏或答题时才调用个人 D1 API。
5. 本轮不更改或删除原有学习、收藏、考试数据；不执行测试记录写入生产 D1。

## 真实设备仍需验收（不可由 CI 代替）

- **iPhone Safari / 主屏 PWA**：日英发音、切换课程停止旧声音、30 秒录音与回听、拒绝麦克风后的提示、后台返回；断网完成语法及听力后恢复网络，不重复提交。
- **iPad Safari 纵横屏**：含两类对话的课程卡不溢出、词典长释义换行、题目下方白板不盖住题目，Apple Pencil 和触摸/鼠标书写正常。
- **跨设备**：iPhone 答一题并在线确认「云端已同步」，换 iPad 重新登录同一日期/语言，确认只显示同一个答案；反向流程再测，确认重新加载不覆盖云端。
- **桌面**：键盘导航、语音与错误/空数据状态、文本和按钮布局。
- **免费额度监控**：Cloudflare D1 Read/Write、Workers 请求、Workers AI 用量；AI 必须由用户主动点选，普通词典查词不得自动调用 AI。

## 边界与不属于已完成的承诺

- FE 约 3,000 道公开真题的扩充目标，和相关 #108 / #112 题库积累任务，**不计入本次「非 FE 扩充」验收**。
- 已发布词条有许可证和来源但不能保证所有读音、词性和复杂语法解释准确；缺失时必须明示不确定性。
- 没有 iPad/iPhone 的真实传感器、浏览器和使用者登录会话时，不得勾选真实设备或跨设备端到端验收。
- 本文是验收记录和入口，不能单靠勾选项声明 2.0 所有目标彻底完成。
